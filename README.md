# Alma Lead Scheduler

Public lead intake form plus an auth-guarded internal UI for attorneys to review leads and mark them as reached out.

- **Backend:** FastAPI + SQLAlchemy + SQLite (`backend/`)
- **Frontend:** Next.js App Router (`frontend/`)

Design decisions live in [docs/Decisions.MD](docs/Decisions.MD). Contributor and architecture rules live in [CLAUDE.md](CLAUDE.md).
